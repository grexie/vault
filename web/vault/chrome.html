ONE-TIME SETUP

Bring Vault to your browser.

You’ll need your paired Vault command and a signing device. Already use Vault on this computer? Start with step 2.

  1. 1

    Get the Vault command.

    Download the package for your computer, extract it, and install the vault executable somewhere on your PATH. Follow the setup guide to pair this computer and connect your signing device.

    Mac · Apple silicon ↗ Mac · Intel ↗ Linux · x64 ↗ Linux · ARM64 ↗

    Pair your computer ↗Checksums ↗

  2. 2

    Connect Chrome to Vault.

    Run this in Terminal on the computer where you use Chrome:

    vault browser-wallet install

    The command installs the extension files and registers the local bridge. It prints the folder to select in the next step. No port, token or extra account to configure.

  3. 3

    Load the extension in Chrome.

    Enter chrome://extensions in Chrome’s address bar. Turn on Developer mode, choose Load unpacked, then select the extension folder printed by Vault.

    The CLI already includes the extension. If you downloaded the ZIP separately, extract it into a permanent folder and select that folder instead.

    This preview is distributed directly by Grexie. It isn’t listed in the Chrome Web Store yet, so a website cannot install it with one click.

A few useful details.

How do I check everything is connected?

Run vault browser-wallet doctor. It checks your pairing, public identities, signing device, cloud connection and Chrome integration. Open the extension popup to check the current website.

Can I keep my other wallet?

Yes. Vault announces itself alongside other installed wallets. Choose Grexie Vault in websites that offer a wallet selector.

Can an AI agent use it?

Yes. An agent can use the same website buttons and wallet selector you do, then wait while you review the request in Vault. A connection shares a public address; it never grants permission for a later signature or transaction. Read the agent instructions ↗

How do I update or remove it?

Update your Vault command, run vault browser-wallet install again, then choose Reload on Vault’s card at chrome://extensions. To remove it, run vault browser-wallet uninstall and remove the Chrome extension. Your Vault identities and pairing remain in place.
