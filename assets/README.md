# Terminal icon

`terminal-icon.png` is original artwork generated with the built-in image-generation tool for this application. `go run cmd/assets/main.go` resizes it reproducibly to 512px, 192px, 180px (Apple touch icon), and 32px (favicon). Notifications use the 192px icon.

Generation brief: a premium 3D rendered terminal app icon, dark forest-green terminal window with a subtly beveled body, inset glass screen and a bold pale-mint `>_` prompt, soft studio lighting, centered mask-safe composition, opaque evergreen square background, no other lettering or objects.
